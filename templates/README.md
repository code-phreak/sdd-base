# Optional Markdown templates

**Copy only the files your project needs.** These are prompts for thinking and recording decisions, not a mandatory folder structure. For simple projects, combine brief, requirements, design and tasks into a small approved plan.

| Artifact | Template |
|---|---|
| Intent and scope | [project-brief.md](project-brief.md) |
| Autonomy and gates | [working-agreement.md](working-agreement.md) |
| Canonical functional requirements | [requirements.md](requirements.md) |
| Measurable nonfunctional requirements | [quality.md](quality.md) |
| Acceptance evidence and exceptions | [acceptance-log.md](acceptance-log.md) |
| Integrated architecture | [architecture.md](architecture.md) |
| Consequential technical decision | [adr.md](adr.md) |
| Decisions and unresolved questions | [decision-register.md](decision-register.md) |
| One increment's requirements | [increment-requirements.md](increment-requirements.md) |
| One increment's technical design | [increment-design.md](increment-design.md) |
| One increment's ordered tasks | [increment-tasks.md](increment-tasks.md) |
| Requirement/verification ownership | [coverage.md](coverage.md) |
| Test strategy | [verification-plan.md](verification-plan.md) |
| Spec/behavior change proposal | [change-proposal.md](change-proposal.md) |
| Threat and mitigation review | [threat-model.md](threat-model.md) |
| Brand/UX design review | [experience-brief.md](experience-brief.md) |
| Operational procedures | [operations-runbook.md](operations-runbook.md) |
| Release readiness | [release-checklist.md](release-checklist.md) |

**Template notation:** Square-bracket placeholders are *not decisions*. Remove them when filling in a real artifact. Label status `Draft` until the developer explicitly approves the document. Never label placeholder acceptance as passed.
