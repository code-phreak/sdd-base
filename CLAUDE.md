# Claude Code entry point

Follow [`AGENTS.md`](AGENTS.md) as the primary operating contract for this repository. Use [`docs/context-routing.md`](docs/context-routing.md) to read only the current phase's relevant documents. Start new work with [`prompts/00-start.md`](prompts/00-start.md); use more specific prompts as authorized.

Do not assume a tool or permission is available. Ask for required authentication, sensitive actions and consequential approvals. Never infer deployment/merge authority from the ability to run a command.
