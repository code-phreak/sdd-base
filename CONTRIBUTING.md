# Contributing

This repository is a **reusable SDD method**, not an example application. Contributions should make the method clearer, safer, more adaptable, or easier for an agent to apply with less context.

- Open an issue or discussion for consequential process changes before submitting a large rewrite.
- Prefer one focused, platform-neutral change per PR; keep examples fictional and secrets absent.
- Preserve the distinction between reusable guidance, optional templates, and project-specific decisions.
- Check that links resolve, prompts agree with `AGENTS.md`, approval gates remain explicit, and tools are not presumed installed.
- Avoid adding stack-specific code, proprietary artifacts, heavy automation, or unnecessary templates. This edition intentionally includes **documentation and prompts only**.
- Describe the problem, proposed behavior, backward-compatibility impact, and how you manually checked the documentation.

Suggested merge method: squash after review. Never merge solely because an AI agent claimed tests passed.
